# לחץ דם — אפליקציה לטלפון עם שמירה ל-Google Sheets

מצלמים את מסך מד לחץ הדם ← זיהוי הטקסט של Google (בחשבון שלך, בחינם ובלי מפתחות) קורא את הערכים (סיסטולי / דיאסטולי / דופק) וממלא אותם —
או פשוט מקלידים ידנית ← "שמור מדידה" ← השורה נכנסת מיד לגיליון Google.
האפליקציה מותקנת למסך הבית עם אייקון, ועובדת גם בלי אינטרנט (המדידה נשמרת בטלפון ונשלחת כשהחיבור חוזר).

> **קוד לגיליון:** צריך להשתמש בקוד מ-`apps-script/Code.gs` שבריפו הזה (ולא בקוד קודם),
> כי רק הוא יודע לקרוא את התמונות ולוודא שהמדידה נשמרה.

```
├── index.html, app.js              ← האפליקציה (PWA)
├── manifest.webmanifest, sw.js      ← התקנה למסך הבית + עבודה בלי רשת
├── icons/                           ← האייקון
└── apps-script/Code.gs              ← הקוד שרץ בחשבון ה-Google שלך ושומר לגיליון
```

ההקמה נעשית פעם אחת, בערך 15 דקות.

---

## שלב 1 — הגיליון והסקריפט

1. פותחים גיליון חדש: <https://sheets.new> ונותנים לו שם (למשל "לחץ דם").
2. בתפריט: **הרחבות ← Apps Script**. (אם הסקריפט נמצא בפרויקט נפרד, מעדכנים בקוד את `SPREADSHEET_ID` למזהה הגיליון.)
3. מוחקים את מה שכתוב שם, מדביקים את כל התוכן של `apps-script/Code.gs` ושומרים (💾).
4. למעלה בוחרים את הפונקציה **setup** ולוחצים **הפעלה**. גוגל תבקש הרשאות — מאשרים
   (אם מופיע "Google hasn't verified this app": **Advanced ← Go to … (unsafe)** — זה הסקריפט שלך).
   ההרשאות כוללות Drive ו-Docs: התמונה עולה לרגע ל-Drive שלך לזיהוי הספרות ונמחקת (לפח) מיד אחר כך.
5. ב-**Execution log** יופיע **קוד הגישה** — שומרים אותו (אפשר לראות אותו שוב מהגיליון:
   תפריט **לחץ דם ← הצגת קוד גישה לאפליקציה**).

## שלב 2 — פרסום הסקריפט כ-Web App

1. בעורך ה-Apps Script: **פריסה (Deploy) ← פריסה חדשה (New deployment)**.
2. סוג: **Web app**. ‏Execute as: **Me**. ‏Who has access: **Anyone**.
3. **Deploy** ← מעתיקים את ה-**Web app URL** (נגמר ב-`/exec`).

> "Anyone" נדרש כדי שהאפליקציה תוכל לפנות לסקריפט. בלי קוד הגישה אף אחד לא יכול לקרוא או לכתוב.
>
> אם משנים את הקוד בהמשך: **Deploy ← Manage deployments ← ✏️ ← Version: New version** — כך הכתובת נשארת אותה כתובת.

## שלב 3 — העלאת האפליקציה לאינטרנט

אפליקציה שמתקינים בטלפון חייבת לשבת בכתובת https. שתי דרכים חינמיות:

**Vercel (מומלץ — כבר יש לך חשבון):**
1. <https://vercel.com/new> ← בוחרים את הריפו `bp-monitor` ← **Import**.
2. **Framework Preset**: ‏**Other** (בלי פקודת build). ‏**Deploy**.
3. הכתובת של האפליקציה: **<https://bp-monitor-six.vercel.app/>**. כל שינוי שנדחף לריפו מתעדכן שם אוטומטית.

**Netlify Drop (בלי חשבון GitHub):** מורידים את הריפו כ-ZIP, פותחים אותו וגוררים את התיקייה לאתר <https://app.netlify.com/drop>.

## שלב 4 — התקנה בטלפון

1. פותחים את הכתובת בטלפון (**אייפון: Safari**, **אנדרואיד: Chrome**).
2. למטה, **הגדרת חיבור לגיליון** ← מדביקים את **כתובת ה-Web App** ואת **קוד הגישה** ← **שמור חיבור** — אמור להופיע "מחובר לגיליון ✓".
3. מתקינים:
   - **אייפון:** כפתור השיתוף ⬆︎ ← **הוספה למסך הבית**.
   - **אנדרואיד:** תפריט ⋮ ← **התקנת אפליקציה**.

האייקון (קו דופק טורקיז על רקע כהה) יופיע במסך הבית.

## איך משתמשים

- **📷 צלם מכשיר** (או **🖼️ העלה תמונה**): מצלמים את המסך מקרוב וישר, בלי השתקפות. תוך כמה שניות המספרים ממולאים.
  **תמיד כדאי לבדוק שהמספרים נכונים** לפני השמירה — אפשר לתקן כל ערך.
- **הקלדה ידנית**: פשוט ממלאים סיסטולי, דיאסטולי ודופק (לא חובה) ולוחצים **שמור מדידה**.
- **מדידות אחרונות**: 20 המדידות האחרונות שנשמרו מהטלפון הזה (⏳ = ממתינה לשליחה).
- בגיליון עצמו: כל המדידות, עמודת **סיווג** צבועה לפי הדרגה, וגרף שמתעדכן אוטומטית.

### הסיווג (לפי ההנחיות האירופיות, ESC)

| סיווג | סיסטולי | | דיאסטולי |
|---|---|---|---|
| נמוך | מתחת ל-90 | או | מתחת ל-60 |
| תקין | עד 129 | ו | עד 84 |
| תקין-גבוה | 130–139 | או | 85–89 |
| יתר לחץ דם דרגה 1 | 140–159 | או | 90–99 |
| יתר לחץ דם דרגה 2 | 160–179 | או | 100–109 |
| יתר לחץ דם דרגה 3 | 180 ומעלה | או | 110 ומעלה |

הסיווג הוא לעזרה במעקב בלבד ואינו תחליף לייעוץ רפואי.

## פתרון בעיות

| בעיה | מה עושים |
|---|---|
| "קוד גישה שגוי" | בודקים את הקוד בגיליון: **לחץ דם ← הצגת קוד גישה**. |
